Guía d'editar i publicar online

  1. Crear la carpeta en el nostre disc dur, treballem en local.
  2. Obrim el programa Visual Studio Code, arrastrar la carpeta al explorador o open folder
  3. Crear new file: index.html
  4. Editem el fitxer
  5. Obrim el navegador i accedim al nostre perfil de github
  6. Crearem un repositori com per exemple el repositori b1
  7. Add load files i upload files
  8. Una vegada l'arxiu index.html apareix en el directori del nostre repositori, anem a settings, en la barra de l'esquerra busquem pages i en github pages canviem a none main i apretem save.
  9. Esperem un poc i actualizem i ens apareixerà la nostra url en el repositori
